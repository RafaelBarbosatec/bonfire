> *This is a [GameComponent](https://github.com/RafaelBarbosatec/bonfire/blob/master/lib/base/game_component.dart)*

Looking for a runnable sample? The
[lighting example](https://github.com/RafaelBarbosatec/bonfire/tree/master/example/lib/pages/lighting)
demonstrates every feature on this page: cutout and additive lights, pulses,
arc flashlights, `animateTo`, `fadeIn`/`fadeOut` and camera rotation.

The lighting layer is composed of two independent pieces:

1. **Ambient darkness**, configured once on `BonfireWidget` through `lightingColorGame`.
2. **Light sources**, added to any component with the `WithLighting` mixin.

```dart
BonfireWidget(
  lightingColorGame: const Color(0xFF000000).withValues(alpha: 0.85),
  // ...
)
```

## Adding a light to a component

Add the `WithLighting` mixin and configure it with `lighting.setup(...)`:

```dart
class Torch extends GameDecoration with WithLighting {
  Torch(Vector2 position)
      : super.withAnimation(
          Future<SpriteAnimation>.value(torchSprite),
          size: Vector2(32, 32),
          position: position,
        ) {
    lighting.setup(
      LightingConfig(
        radius: 120,
        color: const Color(0xFFFFB300).withValues(alpha: 0.35),
        withPulse: true,
        pulseVariation: 0.12,
        pulseSpeed: 0.1,
        blurBorder: 40,
      ),
    );
  }
}
```

Enable or disable a light without removing the component:

```dart
lighting.enabled = false;
lighting.enabled = true;
```

## LightingConfig

| Property | Default | Description |
| --- | --- | --- |
| `radius` | **required** | Radius of the light. |
| `color` | **required** | Color used to fill the light area. Alpha matters: it is the light intensity. |
| `type` | `LightingType.circle` | `LightingType.circle` or `LightingType.arc(...)`. |
| `blurBorder` | same as `radius` | Blur applied to the light edge. `0` gives a crisp edge. |
| `align` | `Vector2.zero()` | Offset of the light relative to the component center. |
| `mode` | `LightingMode.cutout` | How the light interacts with the ambient darkness. |
| `falloff` | `LightFalloff.blur` | How the light fades to the edge: `blur`, `linear` or `smooth`. |
| `innerRadius` | `0.35` | Fraction of `radius` with full intensity in gradient falloffs. |
| `intensity` | `1` | Multiplies the alpha of `color` (`0..1`). |
| `additiveBlendMode` | `BlendMode.plus` | Blend mode used by additive lights (`plus`, `screen`...). |
| `flicker` | `null` | Optional candle-like flicker. |
| `withPulse` | `false` | Enables the pulsing radius. |
| `pulseVariation` | `0.1` | Maximum radius variation, relative to `radius`. |
| `pulseSpeed` | `0.1` | Pulse speed. A full sweep takes `pulseVariation / pulseSpeed` seconds. |
| `pulseCurve` | `Curves.decelerate` | Curve applied to the pulse. |
| `useComponentAngle` | `false` | Keeps the light aligned with the component `angle` (useful for arcs/flashlights). |

### Cutout and additive lights

`LightingMode.cutout` is the classic flashlight: it erases the ambient darkness
inside the shape and tints it with `color`.

`LightingMode.additive` adds light to the scene without erasing the ambient
darkness. It is composited **below** the ambient color, so at night the ambient
tint darkens the glow instead of the glow being painted over the darkness. It
works even when `lightingColorGame` is transparent, so you can use it for
torches, magic, explosions and neon on fully lit maps:

```dart
lighting.setup(
  LightingConfig(
    radius: 90,
    color: const Color(0xFFFF8A00).withValues(alpha: 0.5),
    mode: LightingMode.additive,
    withPulse: true,
  ),
);
```

### Arcs (flashlights, cones)

```dart
lighting.setup(
  LightingConfig(
    radius: 140,
    color: const Color(0xFFFFF3B0).withValues(alpha: 0.4),
    type: LightingType.arc(
      startRadAngle: -0.4,
      endRadAngle: 0.8,
      isCenter: true,
    ),
    useComponentAngle: true,
  ),
);
```

Lights follow the camera transform, so they stay aligned when the camera is
zoomed, moved or rotated (`CameraConfig.angle`).

About the arc parameters:

| Parameter | Meaning |
| --- | --- |
| `startRadAngle` | Angle (radians) where the arc starts, before rotation. |
| `endRadAngle` | **Sweep** of the arc in radians (not the end angle). |
| `isCenter` | `true` centers the cone on the component angle; `false` makes the end of the cone point at the component angle. |
| `radius` | Reach of the light, in the same unit used by circle lights. |

So `LightingType.arc(startRadAngle: -0.4, endRadAngle: 0.8, isCenter: true)`
produces a cone of 0.8 rad centered exactly on the component facing direction.

### Soft falloff without blur

`LightFalloff.blur` keeps the historical `MaskFilter.blur` edge. For a softer,
cheaper edge use a radial gradient instead:

```dart
lighting.setup(
  LightingConfig(
    radius: 160,
    color: const Color(0xFFFFB300).withValues(alpha: 0.35),
    falloff: LightFalloff.smooth, // or LightFalloff.linear
    innerRadius: 0.45,            // 45% of the radius at full intensity
  ),
);
```

`innerRadius` keeps the center of the light at full intensity and the gradient
only covers the outer band, which avoids the washed out look of a uniform blur.
Gradient falloffs also give a proportional (`dstOut`) cut on the ambient
darkness, so the light edge is soft instead of binary.

### Intensity and additive blend mode

`intensity` multiplies the alpha of `color`, so you can reuse the same color
for several lights. For additive lights you can also choose the blend mode:

```dart
lighting.setup(
  LightingConfig(
    radius: 90,
    color: Colors.amber,
    mode: LightingMode.additive,
    intensity: 0.6,
    additiveBlendMode: BlendMode.screen,
  ),
);
```

### Flicker

Candle-like variation applied to both radius and intensity. It is
deterministic, so different lights can have different `seed`s:

```dart
lighting.setup(
  LightingConfig(
    radius: 70,
    color: const Color(0xFFFF8A00).withValues(alpha: 0.5),
    flicker: const LightFlicker(
      frequency: 7,
      amplitude: 0.15,
      seed: 42,
    ),
  ),
);
```

### Lights without a component

For explosions, muzzle flashes or ambient details you don't need a component
with `WithLighting`. Add a `LightSource` to the game lighting layer and remove
it when it is no longer needed:

```dart
final light = gameRef.lighting.addLight(
  LightSource(
    position: someWorldPosition,
    config: LightingConfig(
      radius: 180,
      color: Colors.white.withValues(alpha: 0.9),
      mode: LightingMode.additive,
      falloff: LightFalloff.smooth,
    ),
  ),
);

// Later:
gameRef.lighting.removeLight(light);
```

`LightSource` also has `enabled`, `angle` (used by arc lights) and a mutable
`position`, so you can move it every frame without creating a component.

## Animating the ambient light

The ambient color can be animated through `gameRef.lighting`:

```dart
// Fade the ambient darkness in.
gameRef.lighting.fadeIn(
  const Color(0xFF000022).withValues(alpha: 0.9),
  duration: const Duration(seconds: 2),
);

// Change to another ambient color.
gameRef.lighting.animateToColor(
  Colors.deepPurple.withValues(alpha: 0.7),
  duration: const Duration(milliseconds: 800),
);

// Fade the ambient darkness out.
gameRef.lighting.fadeOut();
```

## Animating a single light

Every light can transition smoothly to another configuration. `radius`, `color`,
`align` and `blurBorder` are interpolated; discrete properties (`type`, `mode`,
pulse settings) switch at the middle of the transition:

```dart
lighting.animateTo(
  LightingConfig(
    radius: 220,
    color: const Color(0xFFFF0000).withValues(alpha: 0.6),
    mode: LightingMode.additive,
  ),
  duration: const Duration(milliseconds: 600),
  curve: Curves.easeOut,
);

// Jump to a configuration immediately and cancel any transition.
lighting.setup(otherConfig);
```

## Performance tips

- Prefer `mode: LightingMode.cutout` with a dark ambient color for classic
  top-down lighting; it uses a single `saveLayer`.
- `blurBorder: 0` is cheaper than a large blur and gives a pixel-art friendly
  crisp edge.
- `LightFalloff.smooth`/`LightFalloff.linear` avoid `MaskFilter.blur` and scale
  better when several lights are visible at once.
- Lights outside the camera are not rendered nor updated. Avoid hundreds of
  pulsing lights on low-end devices.
- `LightingConfig` is immutable. Reuse config instances instead of creating them
  inside `update`.
