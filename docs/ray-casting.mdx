---
title: Ray casting
description: "Cast rays to detect collisions."
---


Ray casting and ray tracing send rays from a point in your game and report what they collide with and how they reflect after hitting something.

Bonfire exposes the [Flame Ray casting](https://docs.flame-engine.org/latest/flame/collision_detection.html#ray-casting-and-ray-tracing) through the game instance (`gameRef`):

```dart
final result = gameRef.raycast(
  Ray2(
    origin: Vector2(0, 0),
    direction: Vector2(1, 0), // must be normalized
  ),
  maxDistance: 100,
);
if (result?.hitbox != null) {
  // collided with `result.hitbox` at `result.intersectionPoint`
}
```

Cast multiple rays at once (e.g. a field of view):

```dart
final results = gameRef.raycastAll(
  Vector2(0, 0), // origin
  numberOfRays: 8,
  startAngle: 0,
  sweepAngle: tau, // 360 degrees (`tau` comes from `dart:math`)
  maxDistance: 100,
);
```

Or trace reflections:

```dart
final hits = gameRef.raytrace(
  Ray2(
    origin: Vector2(0, 0),
    direction: Vector2(1, 0),
  ),
  maxDepth: 10,
);
```

> `gameRef` is available on any component through the `BonfireHasGameRef` mixin. Check the [Flame Ray casting documentation](https://docs.flame-engine.org/latest/flame/collision_detection.html#ray-casting-and-ray-tracing) for details.
